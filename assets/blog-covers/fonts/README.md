# Site font assets

The site reuses the unchanged Latin and Cyrillic WOFF2 assets already checked in
for blog covers. No external font download is needed during build or at runtime.

- Inter 4.001 (git-66647c0bb), variable weight 100–900: SIL OFL 1.1,
  see Inter-LICENSE.txt. https://github.com/rsms/inter
- Roboto Condensed 3.008 (2023), variable weight 100–900: Apache 2.0,
  as identified by these files’ embedded license metadata; see
  RobotoCondensed-LICENSE.txt. https://github.com/googlefonts/roboto

The license texts were copied from local system license distributions, with
copyright notices preserved from the font name tables. These font files were
not converted, subsetted or renamed by this change. JetBrains Mono is used by
the existing cover generator only and is not served by the site font setup.
