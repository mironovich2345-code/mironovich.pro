# Библиотека отраслевых гипотез

Источник: `lib/business-map/dialog/industry.ts`. Расширение — добавление типизированного сценария, без изменения финансовых коэффициентов. Отраслевая статистика не используется.

| ID | Что проверяем | Первый шаг | Метрики |
|---|---|---|---|
| reporting | Ручная управленческая отчётность | Проследить поля одного отчёта и повторный ввод | Минуты с проверкой, переносы, исправления |
| transfer | Перенос между CRM/таблицами/системами | Проследить одну запись и необходимость каждого переноса | Вводы на запись, минуты, расхождения |
| missed-leads | Обращения вне учёта или без ответственного | Сверить последние 30 обращений с CRM | Регистрация, ответственный, время ответа |
| slow-response | Подготовка и передача клиентского ответа | Разделить ожидание и собственно работу | Первый ответ, передача, ошибки |
| onboarding | Повторяющиеся объяснения новичкам | Собрать вопросы и владельца инструкции | Время наставника, ошибки, самостоятельные задачи |
| sales-control | Ручной сбор статусов и контроль планов | Выбрать показатель и значимое отклонение | Время сбора, актуальность, реакция |
| renewals | Ручные проверки продления | Проверить окончания, следующий шаг и согласия | Пропущенные шаги, своевременность, минуты |

Каждый сценарий содержит понятное описание возможной проблемы, признаки, четыре основных вопроса, бесплатное действие, варианты решения, ограничения, данные для расчёта и метрики. Число 30 в сверке обращений — предлагаемая проверочная выборка, не статистика отрасли и не финансовый коэффициент.

Порядок рассмотрения решений: организация → проверка текущей программы → API/детерминированные правила → ИИ только для смысловой работы → индивидуальная разработка → отказ/отсрочка. Реальный порядок зависит от процесса: обычный перенос данных не получает вариант ИИ. Наличие функции конкретной CRM или доступного API не объявляется проверенным. Требуется проверка документации и доступа владельцем.

Для торговли, услуг, агентств и другой сферы используется явно обозначенная универсальная подвыборка. Это не полноценные отраслевые библиотеки. Ни одна карточка не утверждает, что проблема уже доказана.
