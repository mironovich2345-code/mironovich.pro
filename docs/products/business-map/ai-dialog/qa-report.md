# Проверки и визуальная приёмка

Ветка `feature/business-map-ai-dialog`, база `3bbf569b43c49f6d0cede6c235f6d3a45cfdba5b`. Только синтетические данные; локальные серверы, без Railway-деплоя.

## Автоматические проверки

| Команда | Результат |
|---|---|
| `npm test` | 314 тестов, все проходят: прежние калькуляторы/Core/Preview и новые диалог/API |
| `npm run lint` | Успешно, без предупреждений ESLint |
| `npm run typecheck` | Успешно |
| `npm run build` | Успешная production-сборка, закрытый динамический маршрут и серверный API |
| `node scripts/check-business-map-preview.mjs` | 90 успешных HTTP-проверок production-сборки |

Среда: Node 22.23.5. Машинные результаты: [checks.json](checks.json), [http-check.json](http-check.json). В build остаются прежние сообщения release guard о юридических текстах и настройке лимита публичных лидов; они не изменялись этой веткой и не означают деплой. Предупреждение Node о strip-types/module type не является ошибкой тестов.

Новые тесты проверяют не только happy path: unknown без зацикливания, границы чисел/потока, сохранение знака отрицательных чисел и строгий строковый тип enum, нулевой объём, точность и округление, per-person/team, W-CAPACITY и явный рабочий фонд, отсутствие зарплаты, приоритет и статус высокого риска, критические барьеры, отказ от ненужной автоматизации, редактирование и инвалидирование плана, подтверждение/отклонение трактовки и её источник после смены демо/реального ответа.

Серверные тесты используют настоящий handler и подменённый HTTP-транспорт OpenAI. Проверяются официальный URL/контракт Responses, strict JSON Schema, минимальный контекст, store:false, отсутствие tools, цитаты/числа, лишние финансовые поля, качественный Advisor, prompt injection как данные, отказ/неполный/невалидный ответ, 429, таймаут с abort, отсутствие повторов, replay requestId, конкурентный/минутный/суточный бюджет и сброс UTC. Credentials и тестовые ключи генерируются в памяти.

HTTP-прогоны запускают настоящий Next production build с разными окружениями: авторизация HTML/assets/RSC/prefetch, неправильные/отсутствующие credentials, forged headers, noindex, runtime-rotation, закрытые публичные API, новый POST, origin/content-type/body/schema проверки при включённой конфигурации ИИ и production с включёнными флагами ИИ/прототипа. Настроенный маршрут получает только **невалидные** запросы и отклоняет их до провайдера; это не реальный успешный OpenAI-вызов. Публичные `/`, `/tools/labor-cost`, `/tools/automation-cost` в production возвращают 200.

## Браузер и удобство

Проверен видимый Chromium на **375, 768 и 1440 CSS px**. Ширину подтверждает runtime `window.innerWidth` в интерфейсе. Для ограниченного физического рабочего стола использованы zoom 150%, 100%, 75% и изменение размера окна; это реальные CSS-ширины, не растягивание PNG. Скриншоты включают рамку браузера. Это desktop Chromium, не физические iOS/Android и не их экранная клавиатура.

Проверены ввод/кнопки/Enter, Tab и Space для выбора процессов, прокрутка длинного текста, переходы «Диалог/Карта/План» с сохранением разговора, редактирование и пересчёт, раскрытие формул, три сценария, матрица, отказ трактовки, предел пяти процессов, недостаточные данные, W-CAPACITY и критическая цена ошибки. Видимого горизонтального скролла и обрезки содержимого по ширине в проверенных состояниях не обнаружено; DOM-метрики scrollWidth отдельно не снимались.

Во время проверки исправлены: отсутствующие в шрифте стрелки (заменены SVG), перекрытие поля ввода вкладками на невысоком экране, прокрутка к вопросу/последнему результату, сдвиг кнопок при фокусе поля, начало нового документа с заголовка, дублирование ссылки «назад», перенос номера шага и очистка слишком длинного текста при Enter. В пределах короткого viewport на 375 px библиотека и длинные пояснения требуют вертикальной прокрутки; поле ответа и вкладки доступны.

Замер наблюдаемой реакции на выбор отрасли в native-браузере: **895 мс** от действия до полученного снимка. Это включает накладные расходы инструмента, одна локальная выборка с загруженным JS, не percentile latency и не LLM-время. Отраслевые советы не ждут сети по коду. Достижение целевого полного анализа за минуту в исследовании с пользователями не заявляется; реальная LLM latency не измерена.

## Ограничения приёмки

Реальный успешный OpenAI round trip, качество свободных ответов выбранной модели, фактические token usage/latency, внешние возможности CRM и работа на физическом телефоне не подтверждены. Ошибки провайдера/таймауты проверены транспортными тестами; в браузере проверено состояние отсутствующего ключа, не настоящий сетевой отказ OpenAI. Защита расходов — in-memory одной реплики, не распределённая. Интеграцию нельзя объявлять принятой только по этим мокам/демо. Продолжение — [next-steps.md](next-steps.md).
