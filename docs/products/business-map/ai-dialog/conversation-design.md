# Диалог и живая карта

Первый экран предлагает равноправно отрасль и описание. Выбор отрасли даёт библиотеку немедленно, без API. Затем можно дописать текст; выбор не теряется. Для фитнеса доступны семь сценариев. Остальные отрасли явно получают универсальные гипотезы.

Короткий путь: подтвердить ручную работу → объём **всей команды за день** → минуты на выполнение → последствия ошибки. Это четыре основных вопроса; первый практический шаг появляется после подтверждения, часы — сразу после времени. Известные поля пропускаются. «Не знаю» помечает вопрос пройденным, не подставляет среднее и не запускает бесконечное уточнение. Необычный ответ передаётся интерпретатору, если ИИ настроен, но поле остаётся неизвестным до подтверждения.

Число без единиц толкуется только в контексте текущего вопроса: `10` в ответ на «всей командой за день» означает team/day. Свободное «10 отчётов в день» требует уточнения владельца объёма. «Четыре сотрудника делают по десять отчётов» сохраняет исходный per-person объём 10 и преобразует его в team 40 один раз. При неизвестном числе сотрудников задаётся дополнительный вопрос с объяснением необходимости. Число клубов не означает число сотрудников.

`QuickInsight` возвращает раннюю гипотезу/известные H и C, пробелы, W-CAPACITY и полезный шаг. Сценарии, FTE и приоритет не выводятся из коротких ответов. Для них есть необязательная подробная проверка существующим редактором этапа 2. В параметры компании передаются уже известные сфера и системы; численность и цель не выдумываются. Зарплата необязательна.

В desktop диалог занимает 70%, карта 30%; в мобильном режиме — вкладки «Диалог», «Карта», «План». Переходы сохраняют React state и историю. Карта показывает до пяти процессов. При превышении лимита пользователь выбирает кандидатов, никакой шестой процесс автоматически не активируется. Можно редактировать исходные значения, название, подтверждение проблемы, удалять процесс и пересчитывать. Изменение данных аннулирует ранее полученный ИИ-план; запоздавший ответ API не перезаписывает изменённую карту.

У каждого сообщения есть источник: пользователь, отраслевые правила, расчётное ядро, OpenAI либо синтетическое демо. Предложения модели находятся в отдельном блоке «Я правильно понял?»; «Нет, исправить» не меняет карту. Принятие трактовки не подтверждает саму проблему: это отдельный вопрос.

План содержит гипотезу, подготовку, метрики, ограничения, критерии продолжения/остановки. До достаточной оценки он называется планом диагностики, а не уверенным назначением пилота. При критической цене ошибки предлагается остановиться и привлечь специалиста. Универсальный план работает без API; OpenAI может дать качественное объяснение по отдельной кнопке.

Граница продукта показана явно: бесплатно — отрасль, один быстрый анализ и первый шаг; Business Map за 4 934 ₽ — до пяти процессов, сравнение и подробный план. «Открыть полную карту в демо» лишь показывает демонстрационный доступ: не имитирует покупку и не создаёт платёж или аккаунт. Серверного платного ограничения в прототипе нет.

Состояние вкладки не переживает обновление страницы. Демо загружается только по явному выбору и подписано. Голосового ввода нет; будущая транскрипция должна входить через `ConversationInput`, не менять расчётную модель.
