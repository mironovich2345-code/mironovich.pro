## 3. Сборка и воспроизводимость PDF

```bash
node scripts/career/build-safety-materials.mjs           # все PDF + 06-test.md
node scripts/career/build-safety-materials.mjs --test-md  # только 06-test.md
node scripts/career/check-safety-pdfs.mjs                # пересобрать во временную папку и сравнить с коммитом
```

Нужны Chromium через Playwright 1.63.0 (инструмент разработчика, не зависимость проекта) и poppler (`pdftotext`, `pdfinfo`, `pdffonts`). Шрифты берутся из `assets/blog-covers/fonts`. Сборка падает, если текст выходит за поля, шрифт не загрузился или номера страниц оглавления не совпали. В телефонной версии таблицы превращаются в карточки.

`check-safety-pdfs.mjs` сравнивает для каждого PDF число и размер страниц, текст каждой страницы, встроенность шрифтов и набор ссылок. Байты не сравниваются: Chromium пишет в файл дату и идентификаторы. Workflow [ai-career-v3-safety-pdf.yml](../../../.github/workflows/ai-career-v3-safety-pdf.yml) запускает проверку на PR с изменениями исходников и вручную (`workflow_dispatch`); при расхождении пересобранные PDF прикладываются как артефакт.

## 6. Оставшиеся риски и что проверить владельцу до `approved`

1. **Юрист:** пять толкований из реестра; трансграничная передача при использовании конкретных ИИ-сервисов; квалификация первичных B2B-писем как рекламы; формулировка о последствиях без режима коммерческой тайны.
2. **Сверка редакций** с официальным опубликованием и отслеживание вступления в силу изменений 152-ФЗ и 38-ФЗ (срок пересмотра `nextReviewOn` = 2027-05-18 можно сократить).
3. **Объём:** пособие выросло до 28 стр. A4 из-за юридических оговорок; для быстрого чтения добавлена памятка на 2 стр.
4. **Тест:** длина вариантов выровнена, но качество дистракторов стоит проверить на 3–5 реальных менеджерах (не угадываются ли ответы по смыслу).
5. **Устройства:** PDF проверены рендером, а не на физических телефонах и не скринридером.
6. **Воспроизводимость** привязана к Chromium из Playwright 1.63.0; первый запуск нового workflow в GitHub Actions покажет, совпадает ли раскладка на чистом раннере (если нет — пересобрать PDF в CI-окружении и закоммитить).
7. **Публикация:** после проверки заполнить `quality.reviewer` и `reviewedOn`, затем `factualClaimsChecked: true`, `status: "approved"`, `canBePublished: true`. Валидатор не даст опубликовать урок без этого.
