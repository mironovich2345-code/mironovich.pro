# Кабинет AI Career 3.0 — первый интерфейс (issue #48, этап 1)

Статус: **рабочий интерфейс в синтетическом тестовом контуре**. Это не готовый кабинет:
- сохранение прогресса по шагам добавлено в зависимом PR (см. `progress-v3.md`);
- нет «Моих результатов»;
- нет полного маршрута на настоящих уроках, потому что утверждённых уроков нет.

Продажи, реальные платежи и письма выключены. `salesEnabled` и `legalApproved` не менялись, статусы уроков не менялись.

## Где открыть

`/career/v3` — только при `sandboxVisible()`. На production и при закрытом контуре страница и API отвечают 404.

| Шаг | Что происходит |
| --- | --- |
| Допуск | Код тестировщика и подтверждение работы только с синтетическими данными (существующий v2-эндпоинт `tester`) |
| Вход | Учебный email `demo-…@example.invalid` и одноразовый код из тестового почтового стенда (v2 `auth/request`, `auth/verify`) |
| Учебный доступ | Тестовая операция в симуляторе (v2 `orders` и `orders/fixture-complete`), без списания денег |
| Диагностика | 18 вопросов и до двух уточнений из утверждённой анкеты, по одному на экран |
| Моя карта | Строится сервером (#61) по сохранённой диагностике |
| Мой маршрут | Состояние конструктора 30 шагов; при нехватке материалов — честное «не готов» |
| Уроки | Опубликованные уроки (сейчас их нет); в режиме предпросмотра — черновики с пометкой |

## Режимы проверки (только локально)

Оба режима работают, только если выполнены все условия:
- синтетический контур запущен на `127.0.0.1`;
- включён симулятор оплаты `fixture`;
- переменных Railway нет.

| Режим | Как включить | Что даёт |
| --- | --- | --- |
| Обычный | — | Настоящая библиотека: уроков нет, маршрут «пока не готов» |
| Синтетическая библиотека | `node scripts/career/v3-fixture-library.mjs`, затем `CAREER_V3_FIXTURE_LIBRARY=1` | Тестовые «утверждённые» заглушки из `tests/fixtures`. Файл `.career-v3-fixture/library.json` не коммитится и не попадает в сборку. Везде пометка «Синтетическая тестовая заглушка» |
| Предпросмотр черновиков | `CAREER_V3_REVIEW_PREVIEW=1` | Тестировщик читает уроки в статусе review, draft и prototype с плашкой «Черновик на проверке». В подбор и маршрут они не попадают |

## Что проверено

`tests/career-v3-browser.mjs` (Playwright, локальный контур):

- **`content`, 10 проверок:**
  - допуск, вход, учебный доступ;
  - клавиатура: выбор пробелом, «Продолжить» по Enter, фокус переходит на новый вопрос;
  - «Назад» сохраняет ответ;
  - уточнение показывается только по условию;
  - изменение ответа с экрана проверки;
  - ошибка серверной валидации — подставленный свободный текст отклоняется и показывается у вопроса;
  - карта без технических ID и с источниками выводов;
  - честный «маршрут не готов»;
  - пустой список уроков без предпросмотра;
  - нет ошибок консоли и внешних запросов.
- **`fixture`, 11 проверок:**
  - маршрут из 30 шагов на синтетической библиотеке с пометкой;
  - урок из маршрута: все разделы, самопроверка по критериям, образец ответа, мини-тест с разбором, скачивание материала;
  - предпросмотр черновика.
- **`preview`:** все черновики из #57, #59 и #62 (11 уроков вместе с прототипом) открываются универсальным компонентом. Проверка шла на временном локальном слиянии, которое не отправлялось в репозиторий.
- **На каждом экране:**
  - ширины 320, 375, 390, 768, 1024 и 1440 px без горизонтальной прокрутки;
  - контраст текста не ниже WCAG AA — худший замер 4,97:1;
  - у всех полей есть подписи, у кнопок — названия, один `h1`, ориентиры `main` и `nav`.

Скринридеры (VoiceOver, NVDA, TalkBack) вручную **не проверялись**. Проверены только автоматически доступные признаки:
- подписи;
- роли;
- `aria-live` для прогресса и результатов теста;
- `role=alert` для ошибок;
- порядок фокуса.

Старый кабинет v2: браузерные тесты 10/10, интеграция с PostgreSQL 24/24. Интеграция v3 — 11/11.

1. Сохранение прогресса по шагам и артефактов на сервере. Контракт `ProgressRecord` есть, реализации нет.

4. Экспорт (PDF) карты и маршрута.
5. Ручная проверка со скринридерами и на реальных телефонах.
6. Повторная диагностика с сохранением истории и предупреждением об устаревшей карте в интерфейсе. Сервер уже помечает устаревание.
7. Решение о доступе из основного кабинета v2 и единый вход: сейчас v3 переиспользует v2-эндпоинты отдельной страницей.
