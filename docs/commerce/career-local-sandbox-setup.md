# Изолированный тестовый стенд продукта сотрудников

Статус: локальный учебный стенд. Не является магазином и **не** принимает
настоящие платежи, email, документы работодателя или данные клиентов.

Стенд никак не связан с production Railway. Ранее настроенный preview
другого проекта не изменяется. Новая платная Railway-инфраструктура не создаётся.

## Что нужно

- Node.js 22 и Docker Desktop (Windows 10/11 — с WSL2).
- Скопированный локально репозиторий `mironovich.pro`.
- Свободные порты **3300, 3305, 2526, 55433** на вашем компьютере.
- Только вымышленные ответы в диагностике. **Не использовать реальный email.**

В PowerShell из корня репозитория:

```powershell
npm ci
npm run career:local:init
npm run career:local:verify
npm run career:local:start
```

`init` один раз создаёт игнорируемый Git файл `.env.career.local` со
случайными значениями. При повторном запуске существующие секреты не
переписываются. **Не загружайте этот файл в чат, GitHub или Railway.**

Команда `start`:
1. Проверяет синтетическую конфигурацию и отсутствие внешнего ИИ.
2. Запускает в Docker только PostgreSQL 16, доступный с **127.0.0.1:55433**.
   Данные БД временные и хранятся в RAM.
3. Выполняет миграции **исключительно** базы `mironovich_career_test`.
4. Поднимает на loopback имитацию SMTP и платёжного API.
5. Собирает Next.js и открывает учебный кабинет на **http://127.0.0.1:3300/career/sandbox**.

После запуска откройте второй терминал в том же репозитории и получите
временный код допуска:

```powershell
npm run career:local:gate
```

Не публикуйте его. В кабинете подтвердите работу только с учебными данными.
Для входа используйте, например, `demo-qa@example.invalid`.

Когда кабинет попросит шестизначный код входа, откройте третий терминал:

```powershell
npm run career:local:otp -- demo-qa@example.invalid
```

Проверяемый путь: допуск → учебный email → тестовая покупка 1 993 ₽ (без денег)
→ 18 вопросов → 30 шагов → PDF → прогресс → тестовый возврат.

## Остановка и удаление

Нажмите **Ctrl+C** в окне `career:local:start`. Оно завершит локальные
процессы и удалит временную базу. Если ПК был принудительно выключен или
Docker не завершился штатно:

```powershell
npm run career:local:destroy
```

Команда останавливает только контейнер проекта
`mironovich_career_synthetic` и удаляет его временные данные. Не используйте
`docker system prune` или удаление других контейнеров.

## Принципиальные ограничения

- Нет доступного из Интернета адреса. `127.0.0.1` работает только на
  самом компьютере; телефон не сможет подключиться напрямую. Для мобильных
  размеров используется отдельный Playwright QA.
- Нет настоящих API-ключей ЮKassa или OpenAI.
- `CAREER_AI_MODE=rules`, `CAREER_AI_ENABLED=0` и `OPENAI_API_KEY` пуст.
- Запуск с изменённым `CAREER_APP_ORIGIN`, именем БД, внешним провайдером
  или разрешением ИИ отклоняется.
- Не переиспользуются ни Railway production, ни отдельный preview бизнес-карты.
- Если `.env.career.local` уже содержит другую конфигурацию, launcher
  **отказывает в старте** вместо молчаливой замены значений.
- После остановки временная база очищается; прогресс между запусками
  намеренно не сохраняется.

## Что ещё нужно для публичного тестирования

Отдельный серверный контур для людей с контролируемой авторизацией,
изолированной БД, законным размещением ПД, тестовыми платежами, SMTP и
логированием. Не открывать доступ по `*.up.railway.app` и не включать
настоящие платежи без отдельной проверки безопасности, юридической
модели и реальных тестов интеграций.

Команды `npm test`, `npm run lint`, `npm run typecheck` и
`npm run build` остаются обязательными перед публикацией кода.
