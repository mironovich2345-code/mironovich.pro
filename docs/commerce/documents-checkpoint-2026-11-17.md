Подготовка технического MVP разрешена владельцем после этого checkpoint только
на синтетических данных. `legalApproved=false`, `published=false`, `salesEnabled=false`
сохраняются. Реальный ИИ, реальные клиенты, боевые платежи, main и production не
затрагиваются. Дополнительное согласование архитектуры требуется только для
снятия блокера реального запуска, а не для разрешённой тестовой разработки.
