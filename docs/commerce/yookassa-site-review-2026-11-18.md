# Замечания ЮKassa по проверке сайта — 18.11.2026

## Суть замечаний менеджера

1. На странице продукта не видно, как покупатель сможет оплатить заказ, нет кнопки оплаты.
2. Нужны конкретные цены продаваемого товара/услуги; формулировки «от 100 ₽» недостаточны.
3. Допускается выставление счетов как отдельный сценарий, но в этом проекте выбран **приём онлайн-оплаты единственного цифрового продукта для сотрудников**.

## Решение для подключаемого магазина

- **Единственный товар в публичном каталоге:** «Как стать ценнее для компании с помощью ИИ», цифровой доступ на 90 дней.
- **Фиксированная первоначальная цена:** 1 993 ₽, одна диагностика, один анализ, план из 30 шагов, PDF. Цена берётся из `aiCareerCommerce.priceRub`.
- **Кнопка:** «Купить за 1 993 ₽», видна после описания 30 шагов, **неактивна**, пока нет одобрения платежей, юридических документов и работающей коммерческой инфраструктуры. Встроен текст о том, что оплата ещё подключается.
- **Механизм при запуске:** на собственном сайте посетитель вводит email и подтверждения 18+ / оферты; сервер создаёт заказ с неизменяемой суммой 199 300 копеек, провайдер ЮKassa формирует подтверждение оплаты; только независимое подтверждение успешного платежа открывает кабинет по email. Сейчас этот коммерческий путь **отключён**. Работающая синтетическая версия не равна коммерческой.
- **Поставка:** цифровая, без доставки; вход по email, 90 дней с фактической выдачи. `/delivery` и `/offer/ai-career` описывают планируемый порядок.
- **Права покупателя:** контакты и реквизиты `/requisites`, полный возврат и порядок обращений `/refund`, обработка ПД `/privacy`.
- **Бизнес-услуги:** консультации/разработка продаются отдельно по согласованию и договору, без оплаты на сайте. В `/products` компаниям больше не показывается концепт цифрового продукта как доступная к покупке позиция; внутренний проект не удалён из кода.

## Что честно нельзя заявлять ЮKassa как готовое

- Настоящие платежи/чеки, выдача коммерческого доступа и реальная база покупателей не включены.
- Юридическая приёмка продукта и схема обработки ПД ещё не завершены; sandbox только на вымышленных данных. Флаги `salesEnabled=false` и `legalApproved=false`.
- Зачёркнутая 3 990 ₽ — не старая цена реальных продаж, а плановая стандартная. Это раскрыто на странице; при риске неоднозначного толкования следует убрать сравнение, оставив единственную 1 993 ₽.
- Настоящая внешняя проверка публичного deployment, работа кнопки после будущей активации и сквозная реальная тестовая оплата остаются невыполненными.

## Рекомендованный порядок

1. Сначала влить PR #26 (публичный UI и документы), затем PR #31 (эта витрина). Для замечаний ЮKassa не требуется ждать PR #28 (тестовый MVP) или PR #29 (ИИ-пилот). Перед публикацией проверить сборку и видимость на действующем сайте.
2. Проверить `/products`, `/products/ai-career`, `/delivery`, `/offer/ai-career`, `/requisites`, `/refund` после деплоя. Сделать реальные скриншоты 390/1440 px.
3. Отправить менеджеру точную ссылку на товар и объяснить: магазин продаёт только цифровой доступ для сотрудников, фиксированная цена 1 993 ₽; корпоративные услуги не имеют онлайн-оплаты; кнопка присутствует, временно отключена до подключения.
4. До **включения оплаты** решить юридические вопросы и ограничения размещения данных, подтвердить НПД/чеки, протестировать настоящую тестовую ЮKassa, публичные уведомления, выдачу доступа, возврат и повторную оплату.
