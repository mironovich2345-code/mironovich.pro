Координаты — CSS px от верхнего края viewport при начальной загрузке и загруженных локальных шрифтах. Полные значения: [до](before/checks.json), [после](after/checks.json).

| Viewport | Верх CTA консультации до → после | Верх цены сотрудника до → после | Высота Hero до → после |
| --- | ---: | ---: | ---: |
| 375×812 | 622 → 504 | 975 → 658 | 1 057 → 863 |
| 390×844 | 597 → 504 | 926 → 658 | 1 008 → 863 |
| 768×1024 | 599 → 536 | 612 → 409 | 707 → 644 |
| 1024×900 | 273 → 269 | 609 → 431 | 700 → 644 |
| 1440×900 | 279 → 275 | 606 → 437 | 696 → 663 |

В каждом проверенном размере CTA консультации и вся цена с подписью находятся внутри первого viewport. На 375 px кнопка программы заканчивается на 867 px: для её полного появления нужна небольшая прокрутка, около 55 px; название и цена уже видны. Это сохраняет приоритет консультации без добавления дублирующей кнопки или строки цен. На 390 px до полного появления кнопки около 23 px. Видимость и сокращение высоты измерены; повышение конверсии пока не измерялось.

Экспертная оценка «за 5 секунд»: H1 называет обе аудитории; компания видит ИИ/автоматизацию и бесплатное обсуждение; сотрудник — программу, цену и честный статус подготовки. Для подтверждения понимания нужны реальные представители двух аудиторий, а не только браузерная автоматизация.

## Воспроизведение

После `npm ci` и `npm run build` из корня worktree:

```sh
NODE_BINARY=/path/to/node22 \
CHROMIUM_PATH=/usr/bin/chromium \
AXE_SCRIPT=/path/to/axe.min.js \
python scripts/check-dual-audience-hero.py
```

Python Playwright, Chromium и axe-core используются как внешние QA-инструменты, без новых npm-зависимостей. Runner поднимает `next start` только на localhost и случайном порту, удаляет Telegram/OpenAI/Business Map-параметры из окружения, блокирует внешние браузерные запросы и завершает сервер. Build и runner с одним `.next` одновременно запускать нельзя. Вариант `--phase before` использован для наблюдения исходной сборки `a9ee632`; он не подменяет финальный acceptance и требует именно исходной сборки для воспроизведения.
