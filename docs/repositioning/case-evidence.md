# Кейсы, доказательства и разрешения

Сохранены правила `docs/portfolio/evidence-report.md` и разрешения владельца от 11.11.2026. Единственный реестр — `content/projects.ts`; публичные маршруты, главная и sitemap используют только canPublishProject. Новый оффер не является разрешением опубликовать корпоративный кейс.

| Направление / запись | Что подтверждено и планируется | Демонстрация / метрики | Разрешение / итог |
|---|---|---|---|
| Академия / corporate-learning | Прежний аудит подтверждает исходники корпоративных модулей. Независимая версия на базе Metro UP лишь предполагается | Учебные синтетические примеры 5→2 дня, 25→18%; не эффект продукта. Нужны замеры адаптации, аттестации и времени наставника | **Draft, ожидает разрешения**. Корпоративные код, кадры, сотрудники, документы и материалы не копировались. Права на независимую версию не подтверждены |
| KPI / employee-kpi | Подготовлена карточка предлагаемого пилота, не действующее внедрение | Синтетический CSV/Excel, прозрачные правила; пример 20 000→21 600 ₽ только в учебном блоке. Проверять привязку продаж, расхождения и время отчёта | **Draft**. Нет подтверждённых исходников независимого демо/разрешения на корпоративные рейтинги/реальных результатов |
| Аналитика / club-ops | Сохранён разрешённый кейс и исходные доказательства модулей; промышленная завершённость не заявлена | Разрешённый изолированный рендер с синтетикой. Учебные бюджет/прогноз/атрибуция отдельно от кейса. Проверять свежесть данных, сверку, прогноз | **Published на прежнем основании**. Имя CLUB OPS и обезличенный интерфейс разрешены; live demo не развёрнут, публичной кнопки нет |
| Стандарты / branch-standards | Подготовлен план двух клубов в разных городах; реальный пилот не запущен в этой работе | Оригинальная учебная интерактивная таблица статусов. Нет доступа к 2ГИС/Картам/VK/Instagram/Telegram. Проверять ложные срабатывания, покрытие и сроки исправления | **Draft**. Поддержка источников не заявляется до разрешённого API/прав. Нет корпоративных материалов и реальных результатов |
| Клиенты / lead-engine | Предложение на основе внутреннего продукта по заданию владельца; код/эксплуатация не проверены заново | Учебная квалификация и дедупликация без поиска/рассылки. Проверять качество отбора и время подготовки обращения | **Draft**. Не выдаётся за работающий поток клиентов. Голос только после правовой проверки и оснований; холодный рекламный обзвон не стандарт |
| EATLYY | Прежний разрешённый кейс сохранён без новых обещаний | Прежнее разрешённое изображение и формулировки о функциональности исходников | **Published**. Не удалён, не отождествлён с другими приложениями, медицинские и коммерческие результаты не придуманы |

У каждого из пяти направлений в существующем реестре есть task/built, аудитория, состав предполагаемой/разрешённой демонстрации, проверяемые показатели, готовность, sources и permission. Для новых записей built явно начинается с «Планируется». Ссылки на кейс берутся только из публичного подмножества: четыре draft-маршрута возвращают 404.

Отдельно проверяется отсутствие закрытого текста в клиентском JS: одного фильтра маршрутов недостаточно. Общий клиентский импорт навигации отделён от серверного реестра. В полной странице кейса исходный объект с разрешением и датой сохраняется; отключается только ссылка на саму себя, поэтому проверка будущего разрешённого demo URL не теряет данные публикации.

Для live demo одного URL недостаточно: verifiedProjectDemo требует опубликованный разрешённый кейс, HTTPS без встроенных credentials, available=true, дату проверки и разрешение на демо. Сейчас таких записей нет. Недоступных/непроверенных кликабельных демо-ссылок на сайте нет. Учебный блок оффера — оригинальная иллюстрация, не работающий Metro UP/CLUB OPS и не копия клиентской системы.

Для публикации новых кейсов нужны: разрешение правообладателя на код/материалы; проверенный безопасный источник каждого изображения и SHA; подтверждённая готовность/границы; успешная проверка отдельного синтетического demo URL; документированное основание любого реального результата. Даты Git не объявляются сроком внедрения. Реальные данные, документы и изображения сотрудников не переносятся.
