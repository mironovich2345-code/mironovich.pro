# Аудит переходов

Источник дополнительных ссылок — `config/commercial.ts`. Каждая тема находится в `ServiceTopics` на существующей странице; содержание результата и границ — `content/service-topics.ts`. Новых SEO-адресов для этих восьми задач не создавали.

## Восемь дополнительных услуг

| Пункт | Целевой URL и h2 | Результат и ограничения |
| --- | --- | --- |
| Настройка CRM | `/services/automation#crm` → «Настройка CRM» | Воронка, роли, напоминания; один процесс, лицензии и перенос отдельно |
| API-интеграции | `/services/automation#api` → «API-интеграции» | Контролируемый обмен данными; проверка разрешённого API, лимитов и доступов |
| ИИ-помощники | `/services/development#ai-assistants` → «ИИ-помощники» | Поиск по разрешённым материалам/черновики; контроль качества и человек |
| ИИ-тренажёры продаж | `/services/training#sales-trainers` → «ИИ-тренажёры продаж» | Учебные диалоги и критерии; без обещания роста продаж |
| Голосовые ИИ-интеграции | `/services/automation#voice-ai` → «Голосовые ИИ-интеграции» | Согласованный голосовой сценарий; правовая проверка, основания звонков, API; холодный рекламный обзвон не включён |
| Специализированные CRM | `/services/apps#custom-crm` → «Специализированные CRM» | Приложение под процесс; сначала сравнение с готовой CRM |
| Техническая экспертиза | `/services/expertise#expertise` → «Техническая экспертиза» | Выводы и риски по коду/смете; объём отчёта заранее, без обязательной разработки |
| Техническое сопровождение | `/services/support#support` → «Техническое сопровождение» | Приоритеты, изменения и отчётность; согласованные часы и сроки, без 24/7 |

Для всех восьми предусмотрен CTA «Обсудить эту задачу» к существующей форме `#contact`. Переходы проверяются как кликом из раскрытия на главной (App Router), так и открытием полного URL в свежем документе. HTTP-проверка относится к пути до `#`; браузерная — к самому якорю и заголовку.

Глобальный `scroll-padding-top: 72px` учитывает sticky header. Скрипт проверяет фактический `getBoundingClientRect()` каждого h2: верх ниже нижней границы header, весь заголовок в viewport. Матрица результатов для пяти ширин находится в `topicLinks` в [after/checks.json](after/checks.json); финальный статус — в [QA](qa-report.md).

## Остальные обязательные переходы

| Вход | Назначение | Критерий |
| --- | --- | --- |
| Hero «Обсудить проект» | `/#contact` | Существующая форма и событие `cta_click/hero` |
| Hero «Рассчитать» | `/tools/labor-cost` | Работающий бесплатный калькулятор; формулы прежние |
| Hero «О программе» | `/products/ai-career` | 1 000 ₽, шесть пунктов содержания, явное «пока не продаётся» |
| Шесть строк направлений | Пять `/solutions/*` и `/services/cto` | Состав первого этапа, его цена, CTA к форме |
| Сравнение CTO | `/services/cto` | 150 000 ₽/мес., до 30 часов, состав и ограничения |
| «Посмотреть все возможности» | `/services` | Существующий каталог со старыми страницами |
| Кейсы главной | `/projects`, `/projects/eatlyy`, `/projects/club-ops` | Только разрешённый реестр и прежние статусы |
| Каталог инструментов | `/tools/automation-cost` | Ссылка сохранена и доступна |
| Старые ссылки главной | `/#services`, `/#about` | Совместимые IDs сохранены |

Все публичные адреса из sitemap проходят HTTP/SEO smoke. Четыре неподтверждённых корпоративных кейса, неизвестное решение, прототип Business Map и его chat API проверяются на 404 и отсутствие в sitemap. Не подтверждённые внешние demo URL не выводятся как кликабельные ссылки. Политика и согласие остаются доступны с прежним `noindex`.
