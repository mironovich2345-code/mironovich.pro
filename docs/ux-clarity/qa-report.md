## Воспроизведение браузерного QA

Используются Python Playwright, Chromium и axe-core вне npm-зависимостей проекта. Из корня после сборки:

```sh
NODE_BINARY=/path/to/node22 \
CHROMIUM_PATH=/usr/bin/chromium \
AXE_SCRIPT=/path/to/axe.min.js \
python scripts/check-ux-clarity.py
```

Не запускать build одновременно с сервером QA, использующим тот же `.next`. Скрипт сам создаёт локальный `next start` на случайном порту и завершает его. Удаляет из окружения Telegram/OpenAI/Business Map-параметры, блокирует внешние запросы и использует только вымышленные поля формы. Без `AXE_SCRIPT` скрипт явно помечает axe как SKIPPED; в итоговом прогоне axe обязателен и подключён.

Исходный захват: [before/capture.py](before/capture.py), [before/checks.json](before/checks.json). Для повторения нужна отдельная сборка базы `a53537b`; `QA_ROOT` может указывать её worktree. Сценарии исторической переупаковки в `scripts/check-repositioning.py` описывают прежний Hero и пять карточек. Новый runner сохраняет его проверки публикационных ограничений, SEO, синтетических примеров и доставки формы и обновляет ожидания под это задание.

## Исправления по ходу QA

- В выбранном локальном шрифте диагональная стрелка отображалась отсутствующим глифом. В новых CTA используется поддерживаемая горизонтальная стрелка.
- На 320 px длинное слово «Специализированные» в тематическом h2 расширяло документ с 320 до 323 px. Уменьшен минимальный размер этих заголовков с 28 до 24 px; проверка измеряет и страницу, и внутренние контейнеры, без скрытия overflow.
- В runner уточнены технические ожидания: список глав отделён от breadcrumbs, полное открытие якорного URL начинается со свежего документа, событие native `toggle` ожидается после его асинхронной доставки. Требования к UI, значения цен и критерии отсутствия overflow сохранены.

## Ограничения проверки

Физический телефон, Safari, TalkBack/VoiceOver и настоящее исследование с посетителями недоступны. Автоматическая проверка WCAG не заменяет полный аудит доступности. Production-доставка Telegram и получение событий реальным счётчиком не проверены. Кнопка отправки в локальной среде должна показать ошибку 503 при отсутствии транспорта и не создавать событие успеха. Настоящих лидов не отправляли.

Существующие предупреждения build: прежние `/privacy` и `/consent` выпускаются по решению владельца от 2026-11-01; новые юридические проекты содержат незаполненные поля и не публикуются; IP rate limit не включён без подтверждения окружения. Эти настройки и документы в задаче не изменялись.

## Итог браузерных проверок

Chromium **156.0.8078.79**, axe-core **4.14.0**, WCAG 2 A/AA и 2.1 AA. Итоговый [checks.json](after/checks.json) содержит `passed: true`; код завершения runner — 0.

- **67 HTTP/SEO проверок:** 58 URL sitemap с корректными canonical, description, Open Graph и JSON-LD; 2 прежние юридические страницы с noindex; 7 закрытых/неизвестных маршрутов с 404. URL продукта и новая OG-обложка проверены.
- **35 групп браузерных сценариев** на пяти ширинах. Все три CTA Hero, пять решений и шестая строка CTO, сравнительный блок, каталог, четыре основные аудитории и дополнительные операционный/продажный пути.
- **40 сочетаний «тема × ширина»** для восьми дополнительных услуг. В каждом проверены клиентский переход и полное открытие URL, соответствующий h2 ниже sticky header, результат, CTA и форма.
- **10 проверок** прежних якорей `/#services` и `/#about`. Ссылка «Посмотреть все возможности», открытие/закрытие disclosure, Enter, Space, Escape, фокус и закрытие меню после смены маршрута проходят.
- **337 проверок раскладки:** ни горизонтального скролла документа, ни переполнения проверяемых внутренних контейнеров. **130 axe-проверок:** 0 нарушений, включая открытое меню, раскрытые дополнительные услуги и тематические страницы.
- Ошибок JavaScript — **0**, внешних браузерных запросов — **0**, фрагментов закрытых кейсов в клиентских JS-файлах — **0**. Публичные case assets — только EATLYY/CLUB OPS; публикационный реестр не менялся.
- Форма: `form_start` один раз за сессию, согласие блокирует POST, расширенных полей нет. На 375 px один синтетический запрос к настоящему локальному `/api/lead` вернул **503** без транспорта; показана ошибка доставки, событие успеха отсутствует. Это не проверка реальной доставки Telegram.
- Снимков: **47 BEFORE** (45 экранных + 2 полные главные) и **101 AFTER** (99 экранных + 2 полные главные). Они относятся к одной и той же сетке ширин; содержат синтетические примеры, без реальных полей компаний.

`git diff` отдельно проверен по калькуляторам, Business Map AI, API заявки, аналитическому согласию, юридическим документам, реестру кейсов и зависимостям: изменений в этих защищённых областях нет. Изменение аналитики ограничено идентификаторами CTA и событием раскрытия.

Остаются внешние ограничения: физические устройства/скринридеры и участники UX-тестов не проверялись, работающих внешних live demo нет, корпоративным кейсам нужны разрешения, production-доставка Telegram и счётчика не подтверждена.
