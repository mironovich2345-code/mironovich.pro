# Изменения содержания и аналитики

## Тексты и композиция

- H1: «Разрабатываю системы для управления сотрудниками, продажами и филиалами». Основное действие: «Обсудить проект». Подзаголовок объясняет обучение команды, результаты и порядок в работе простыми словами.
- Hero: бесплатный расчёт ручного труда и отдельная программа для сотрудников. Каждая карточка — одна ссылка целиком, с различимой аудиторией, назначением и ценой/статусом.
- Пять больших карточек заменены шестью строками. Полные оценки, функциональность и ограничения первого этапа остаются на подробных страницах. `SolutionCard` сохранён как компонент.
- `ai-career`: новое название и описание, планируемая цена 947 → 1 000 ₽, новая обложка и Open Graph. Существующие slug, шесть глав, суть, отсутствие гарантий трудоустройства и `preparing` сохранены. Растровая обложка создана инструментом генерации изображений по прежней фирменной обложке; это графика продукта, не клиентский кейс. Старый SVG оставлен для совместимости с ранее опубликованными ссылками.
- С главной убраны подробные Problems, Scenarios, Diagnostics, FreeTools и длинные About/Process. Их файлы сохранены. Короткий `WorkApproach` объединяет три шага и прежний опыт автора, без новых утверждений о клиентах.
- Добавлено сравнение типичных договорных ролей. В нём прямо оговорено, что программист и агентство тоже могут управлять работами по договорённости.
- «Все услуги и прежние направления» → «Посмотреть все возможности». Каждая дополнительная задача ведёт к тематическому h2, результату, ограничениям и CTA. Подробные старые SEO-страницы доступны по прежним URL.
- EATLYY и CLUB OPS отображаются из прежнего реестра с прежними статусами. Закрытые кейсы и права публикации не редактировались. Недоступных внешних demo-ссылок в интерфейсе нет; учебные примеры помечены синтетическими.

## События

Используется существующий `track`, та же Яндекс Метрика и тот же механизм согласия. Новые поля содержат только фиксированные идентификаторы. Систему согласия, загрузку внешнего счётчика, атрибуцию и форму не меняли.

| Действие | Событие | Фиксированные параметры |
| --- | --- | --- |
| Калькулятор Hero | `cta_click` | `location=hero_calculator`, `tool=labor` |
| Программа 1 000 ₽ | `cta_click` | `location=hero_product`, `product=ai-career` |
| Каждое из пяти решений | `cta_click` | `location=direction_list`, `solution=<один из 5 slug>` |
| Шестое направление CTO | `cta_click` | `location=direction_list`, `service=cto` |
| Сравнение CTO → состав | `cta_click` | `location=cto_comparison`, `service=cto` |
| Открытие дополнительных услуг | `additional_services_open` | `location=other_services`; закрытие не считается открытием |
| Дополнительная услуга | `cta_click` | `location=other_services`, `service`, `topic=<один из 8 id>` |
| Тема → форма | `cta_click` | `location=service_topic`, `service`, `topic` |
| Первое взаимодействие с формой | `form_start` | Прежнее событие один раз за сессию, без значений полей |
| Подтверждённая доставка заявки | `lead_submit_success` | Прежние безопасные UTM; только `res.ok && data.ok === true && data.delivered === true` |

`product` и `topic` проверяются по закрытым спискам, неизвестные значения отбрасываются. Общий whitelist не пропускает имя, контакт, компанию, содержимое задачи или иные произвольные поля. Существующая нормализация `page`, проверка персональных данных в UTM и ограничение токенов сохранены. Отладочная очередь в памяти используется QA; реальная доставка событий счётчику без production-ID и согласия здесь не проверялась.

Финансовое ядро, Business Map AI, API заявок, калькуляторы и юридические документы не менялись. Форма по-прежнему не запрашивает новые поля компании/направления при выключенном расширенном режиме.
