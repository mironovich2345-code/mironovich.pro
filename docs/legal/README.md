# Юридические тексты — ПРОЕКТ, НЕ ПУБЛИКОВАТЬ

Статус: черновик для проверки юристом. На сайте сейчас опубликованы прежние тексты
(`app/privacy/page.tsx`, `app/consent/page.tsx`), они не менялись.

Черновики описывают то, что сайт делает фактически (проверено по коду на дату
подготовки). Это не юридическая консультация. Реквизиты оператора не заполнены
намеренно — они не выдумываются.

## Что блокирует публикацию

1. Реквизиты оператора: ФИО, статус (ИП / самозанятый / физлицо), ИНН/ОГРНИП, email
   для обращений субъектов ПД.
2. Включена ли в продакшене Яндекс Метрика и/или Google Analytics
   (`NEXT_PUBLIC_YANDEX_METRICA_ID`, `NEXT_PUBLIC_GA_ID` в Railway). От этого зависит
   раздел «Аналитика» — оставить один из вариантов.
3. Вопросы юристу:
   - Telegram (Telegram Messenger Inc., серверы вне РФ) используется как канал
     доставки заявок — нужна ли оценка как трансграничной передачи и уведомление
     Роскомнадзора;
   - хостинг на Railway (иностранный провайдер) и требование о локализации при
     сборе ПД граждан РФ (ч. 5 ст. 18 152-ФЗ): сайт не ведёт собственной базы заявок,
     но запрос с данными проходит через сервер хостинга;
   - Google Analytics, если включена, — та же оценка трансграничной передачи;
   - нужно ли уведомление Роскомнадзора об обработке ПД для вашего статуса;
   - нужен ли cookie-баннер, если аналитика включена.
4. Включение полей «Компания» и «Направление» (`NEXT_PUBLIC_LEAD_FORM_EXTENDED=1`)
   — только вместе с публикацией согласованных текстов.

## Фактическая обработка (по коду)

| Что | Где в коде | Куда уходит |
|---|---|---|
| Имя, контакт (телефон или Telegram), описание задачи, отметка согласия | `components/LeadForm.tsx` | `/api/lead` → Telegram Bot API → закрытый чат владельца |
| Компания (необязательно), направление — только при включённом флаге | то же | то же |
| Источник визита: utm_source/medium/campaign/content, referrer, страница входа | `lib/attribution.ts` | хранится в localStorage браузера (`mrnv_attr_v1`), передаётся вместе с заявкой в Telegram |
| Факт начала заполнения формы | `lib/analytics.ts` | sessionStorage (`mrnv_form_start_v1`), событие в аналитику без содержимого полей |
| IP-адрес | `app/api/lead/route.ts` | только в оперативной памяти сервера (до перезапуска приложения) для ограничения частоты отправки; не записывается на диск и не пересылается |
| События аналитики (клики по CTA, старт формы, успех/ошибка отправки) | `lib/analytics.ts` | Яндекс Метрика / GA — только если задан ID; содержимое полей не передаётся |
| Сайт собственной базы заявок не ведёт | — | — |
