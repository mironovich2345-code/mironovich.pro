## 3. Текущая схема (новая версия сайта, не опубликована)

```
Браузер ──HTTPS──▶ Railway (хостинг, США/ЕС/Сингапур — регион проверяется)
                     приложение Next.js: проверка и очистка, без базы данных
                     │
                     └──HTTPS──▶ Telegram Bot API ──▶ закрытый чат оператора

Браузер ──(только после «Разрешить»)──▶ Яндекс Метрика (ООО «Яндекс», РФ)
                                        Google Analytics 4 (Google)
```

| Действие с ПД (в техническом смысле) | Где |
|---|---|
| Первичный сбор (данные покидают устройство посетителя) | Сервер Railway |
| Запись в постоянное хранилище | Чат Telegram |
| Хранение заявок | Чат Telegram (облако) + устройства оператора; бессрочно, пока не удалены вручную |
| Хранение факта и редакции согласия | Только внутри того же сообщения Telegram |
| Передача | Railway → Telegram |
| Логи | Railway: в логи приложения данные заявок не пишутся; логи платформы (HTTP) содержат IP, путь, user-agent **всех** посетителей сайта |
| Хранилище браузера | `mrnv_attr_v1` (источник визита, уходит только с заявкой), `mrnv_form_start_v1`, `mrnv_analytics_consent_v1` |

Ни один серверный этап не находится в РФ.

## 7. Предлагаемая схема: хранение в РФ, Telegram без ПД

Подробно — `rf-notify-only.md`. Совместима с A и B.

```
Браузер ──HTTPS──▶ Сервер в РФ: приём заявки
                     ├─▶ PostgreSQL в РФ: заявка + запись о согласии
                     └─▶ Telegram: «Новая заявка №123 · 01.11 14:05 · /contact»
                                    (без имени, контакта, текста, UTM)

Оператор ──HTTPS + вход (пароль + одноразовый код)──▶ Кабинет на сервере в РФ
                                                       просмотр, удаление, выгрузка
```

- В Telegram нет ни одного поля заявки: только порядковый номер, время,
  страница и ссылка на кабинет. Номер не позволяет ничего узнать без входа.
- Запись о согласии хранится отдельно от заявки: редакция, хеш текста, время,
  ID заявки. Срок хранения записи о согласии может отличаться от срока заявки
  (решает юрист).
- Кабинет доступен только оператору: пароль + TOTP-код, сессия 12 ч, журнал
  входов и просмотров.
- Удаление по сроку — автоматически, ежедневно; удаление по запросу — кнопкой
  в кабинете.

Вопрос юристу: достаточно ли такой схемы, чтобы снять вопросы B4а, B5–B7 по
заявкам (остаются Railway — если вариант A — и GA4).

## 8. Railway: какие факты нужно получить

Railway Corporation — американская компания. По [публичному DPA](https://railway.com/legal/dpa)
основная обработка — в США; передачи из ЕС/UK — на основе Data Privacy
Framework или SCC. Субпроцессоры по DPA — с общим разрешением заказчика и
правом возразить в течение 10 дней; перечень — в Trust Center Railway.

| Факт | Зачем | Где взять | Что известно (проверить) |
|---|---|---|---|
| Регион сервиса | Страна первичного сбора | Railway → сервис → Settings → Region | [Регионы по документации](https://docs.railway.com/deployments/regions): US West (Калифорния), US East (Вирджиния), EU West (Амстердам), Southeast Asia (Сингапур). РФ нет |
| Юрлицо и страна | Получатель в политике (§4) | [DPA](https://railway.com/legal/dpa), условия использования | Railway Corporation, США |
| HTTP-логи: состав | Какие ПД посетителей хранит платформа | [Logs](https://docs.railway.com/observability/logs), вкладка HTTP Logs | По документации и форуму — метаданные (IP, путь, статус, user-agent), без тела запроса |
| Логи: срок хранения | Сроки в политике | Поддержка Railway (письменно) | Документация: 7 дней Hobby, 30 дней Pro, до 90 дней Enterprise; ответ на форуме — физическое удаление через 90 дней для всех. **Противоречие — подтвердить у поддержки** |
| Резервные копии | Где и сколько хранятся копии | Документация / поддержка | Сервис сайта без базы и томов — пользовательских данных в бэкапах нет; хранятся образы сборок и переменные окружения (секреты, не ПД посетителей) — подтвердить |
| Субпроцессоры | Получатели и страны | Trust Center Railway | Публикации упоминают Google Cloud, AWS, Cloudflare, Stripe, DataPacket — **неофициально, сверить с Trust Center** |
| Удаленный доступ поддержки | Страны доступа | Поддержка Railway | Полного перечня стран в публичных материалах нет |
| Подписание DPA | Договорная основа | Railway → Compliance (self-service) | Доступно самостоятельно по [Compliance](https://docs.railway.com/enterprise/compliance) |
| Тариф проекта | Определяет срок логов | Railway → Workspace → Billing | — |

Telegram и Google — аналогичные вопросы (юрлицо, страны, сроки); ответы по
условиям этих сервисов юрист оценивает сам.
