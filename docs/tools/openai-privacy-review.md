# Дополнение для юридической проверки — НЕ опубликовано

Базовые рекомендации и формулы работают в браузере и не используют OpenAI. Выбор задач и числовые замеры могут передаваться между двумя инструментами только в sessionStorage вкладки до 24 часов. Описание задачи не сохраняется в этом хранилище. Заявка на услуги — отдельный процесс по действующему согласию, с самостоятельной отправкой; ИИ-уведомление не заменяет согласие на заявку.

Предлагаемый текст отдельного ИИ-уведомления: «По вашему действию сайт отправит в OpenAI только категории задач, число сотрудников, выбранные типы программ и последствия ошибки. Описание, контакты, документы, пароли и расчёт стоимости не передаются. Можно получить базовый разбор без OpenAI». До запроса нужен отдельный checkbox и явная кнопка.

Даже перечисления могут связываться с техническими данными запроса. Не называть их юридически анонимными без оценки специалиста. Сервер обращается в OpenAI; конечный IP посетителя и browser cookies не проксируются в запрос модели приложением. Инфраструктурные access logs Railway/OpenAI имеют собственные правила, которые нужно проверить. Приложение не логирует payload и ключи.

До публикации дополнить действующие privacy/consent после согласования:

- Полное юридическое лицо контрагента OpenAI и роли участников по договору конкретного API-проекта; страны обработки/хранения, основания передачи и необходимые уведомления/локализация по применимому праву.
- Точный состав технических данных, цель выдачи предварительной рекомендации, правовое основание и сроки. Проверить, нужен ли отдельный состав согласия для внешней обработки в данной конфигурации.
- store:false — не обещание нулевого хранения: проверить abuse monitoring, доступные ZDR/MAM и договорные условия аккаунта. Не утверждать, что ZDR включён.
- Ограничение использования по региону, санкционные/договорные требования и допустимость покупки/доступа. Не обходить ограничения поставщика.
- Порядок обращения/отзыва и его последствия; сохранение альтернативного базового разбора без OpenAI.
- Связь с sessionStorage и техническими логами, доступы оператора, политика удаления и механизмы защиты ключа.

Существующие опубликованные тексты, юридический release guard и config/legal.json не изменены. API до проверки выключен одновременно environment-флагом и отдельным кодовым gate, см. ai-recommendations.md. Этот файл не даёт разрешения на внешнюю обработку.
