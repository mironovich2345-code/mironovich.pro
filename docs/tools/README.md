# Инструменты MIRONOVICH.PRO v2

Два прежних URL сохранены: `/tools/labor-cost`, `/tools/automation-cost`. Для локального предпросмотра достаточно Node 22, `npm ci`, `npm run dev`. Ключи OpenAI и Telegram для базовой рекомендации не нужны. Внешний ИИ выключен до отдельного юридического и бюджетного согласования.

- [Дополнение для юридической проверки, не опубликовано](openai-privacy-review.md)

Формулы и валидация v2 — `lib/tools/guided.ts`; проверяемые рекомендации — `catalog.ts`; серверный Responses API — `recommendation-api.ts` и `/api/tools/recommendation`; code gate — `config/ai-recommendations.ts`. Сценарии UI объединены в GuidedCalculator, маршруты используют прежние LaborCalculator/AutomationCalculator. Старые числовые модели и Wizard сохранены для совместимости, но в новом публичном сценарии не вызываются.

Сначала базовая польза, затем необязательные замеры и отдельно ИИ-действие. Стоимость рабочего времени не названа экономией; процент автоматизации, бюджет внедрения и сроки не генерируются.

На странице результата сразу видны проблема, решение и первый практический шаг одного процесса. Другие задачи, проверки, условия пилота и замеры раскрываются отдельно. Текущая модель только уточняет приоритеты и выбирает подходы из каталога; произвольное описание бизнеса не анализируется.

Если сервер не разрешает интеграцию, блок OpenAI полностью отсутствует в интерфейсе. Посетителю доступны базовые рекомендации и замеры; браузер не запрашивает недоступную функцию.
