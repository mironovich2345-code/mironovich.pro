# Тест реальной доставки заявки в Telegram

Цель: убедиться, что заявка с сайта доходит в Telegram, не используя боевой чат
для мусорных сообщений и не раскрывая секреты.

## Что проверено без реального Telegram

Сервер `app/api/lead/route.ts` проверен с подменой запроса к `api.telegram.org`:
формат сообщения, экранирование HTML, поле «Страница», источник визита, ответы на
ошибки (Telegram отказал → 502, недоступен → 502, переменные не заданы → 503),
лимит частоты, ловушка для ботов, проверка Origin и размера запроса. Токен и
chat_id не попадают в клиентский JavaScript и HTML.

## Что нужно от владельца

Один из вариантов (рекомендую **А**):

**А. Тестовый бот в отдельном окружении Railway**
1. В @BotFather создать отдельного бота, например `mironovich_test_bot`.
2. Написать этому боту `/start` со своего аккаунта, получить свой chat_id
   (как в DEPLOYMENT.md, шаг 8) — **в отчёты и чаты его не вставлять**.
3. В Railway создать окружение (environment) `staging` для этой ветки или
   временный сервис из ветки `claude/busy-carson-4j9hr7`.
4. Задать в нём `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` тестового бота,
   `NEXT_PUBLIC_SITE_URL` — адрес staging. ID аналитики **не задавать**, чтобы
   тест не попал в статистику.

**Б. Боевой бот, но после деплоя** — одна контрольная заявка сразу после релиза
с пометкой «ТЕСТ» в тексте. Минус: проверка происходит уже на продакшене.

## Сценарий теста

Все заявки — с вашими собственными данными, текст начинается со слова «ТЕСТ».

| # | Действие | Ожидаемый результат |
|---|---|---|
| 1 | `/contact`: имя, `@ваш_username`, «ТЕСТ контакт», согласие → отправить | На сайте «Заявка отправлена». В тестовом чате сообщение: имя, контакт, задача, «Страница: /contact», дата по Москве, блок ИСТОЧНИК |
| 2 | Открыть `/services/apps?utm_source=test&utm_medium=manual&utm_campaign=h` в **новом приватном окне**, отправить «ТЕСТ услуга» | «Страница: /services/apps», Source test, Medium manual, Campaign h, Landing /services/apps |
| 3 | Главная, форма внизу, телефон `+7 …` | «Страница: /», телефон в поле «Контакт» |
| 4 | Отправить 6 заявок подряд за минуту | 6-я: ошибка на сайте и запасная ссылка на Telegram `t.me/mironovich_pro`; в чат пришло 5 |
| 5 | (только staging) Временно указать неверный `TELEGRAM_CHAT_ID`, отправить | На сайте ошибка доставки и ссылка на Telegram, **нет** сообщения «Заявка отправлена» |
| 6 | Вернуть верный `TELEGRAM_CHAT_ID` | Заявки снова доходят |

После теста: удалить тестовые сообщения из чата; тестового бота можно оставить для
следующих релизов или удалить в @BotFather (`/deletebot`).

## Чего не делать

- Не вставлять токен и chat_id в отчёты, чаты, issue и коммиты.
- Не отправлять тестовые заявки с чужими контактами.
- Не включать `NEXT_PUBLIC_LEAD_FORM_EXTENDED` для теста — расширенная форма ждёт
  утверждения юридических текстов.
