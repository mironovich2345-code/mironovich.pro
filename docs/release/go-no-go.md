## Юридический Go — что нужно решить

1. Email для обращений по ПД (владелец).
2. Адрес оператора для юридически значимых обращений (владелец + юрист).
3. Схема локализации: допустим ли приём через Railway и хранение в Telegram или
   нужен приём/запись в РФ (юрист; при «нужен» — отдельное техническое решение).
4. Трансграничная передача: Telegram, Railway, Google — признавать ли такой,
   процедуры до передачи, формулировки согласия (юрист).
5. Уведомление Роскомнадзора об обработке ПД и о трансграничной передаче —
   нужно ли для самозанятого и подано ли (юрист / владелец).
6. GA4: оставить при согласии в баннере или отключить (юрист → владелец).
7. Сроки хранения заявок и данных аналитики; основание обработки IP для защиты
   формы (владелец + юрист).
8. Точный список и сроки cookies — снять с опубликованного сайта (владелец).
9. Утвердить итоговые тексты политики, согласия и баннера (владелец + юрист).

После этого: заполнить поля, `published: true`, `required` в Railway — сборка
проверит остальное.
