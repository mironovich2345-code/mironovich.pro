# Подготовленные, но не внесённые изменения

Каждое изменение вносится только после отдельного согласования владельца.

## rate-limit-ttl.patch — удаление IP из памяти через минуту

**Проблема.** Лимит запросов к форме (`app/api/lead/route.ts`) хранит IP в
`Map`. Отметки времени старше минуты отбрасываются, но сам IP остаётся в
памяти до перезапуска процесса или накопления 5000 адресов; при 5000 сброс
обнуляет лимиты всех сразу.

**Исправление.** Новый модуль `lib/rate-limit.ts`, `route.ts` использует его:
- каждый IP удаляется не позже чем через минуту после последнего запроса —
  проверка по таймеру (раз в минуту, не держит процесс) и при каждом запросе;
- при переполнении удаляются самые давние адреса, а не все;
- поведение лимита прежнее: 5 запросов в минуту с одного IP, 6-й — 429.

**Проверено** (изменение затем откачено):
- lint, typecheck;
- модульный тест: 6-й запрос блокируется, после минуты разрешён, неактивные IP
  удаляются таймером и при запросе другого IP, переполнение вытесняет самый
  давний адрес и не сбрасывает остальных;
- на сборке: 5 × 200, затем 429, 429; запрос с другого IP — 200.

**Применить:**

```bash
git apply docs/proposals/rate-limit-ttl.patch
```

Затем `npm run lint && npm run typecheck && npm run build`.
